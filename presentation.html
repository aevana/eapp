What was Implemented

Three core deliverables shipped under this epic
LiveRamp · Clean Room Engineering 6
Implementation
  • ✓
    Constraint Violation Fixes on List Questions
    Resolved the root cause of RampID projection and column-append errors that were failing customer queries.
  • 🔄
    Common-Domain Transcoding  Transcoding + RampIDEncoding FF
    Every dataset is transcoded to the CR Owner's domain. Controlled under a feature flag.
  • 📤
    Export Transcoding
    If RampID is part of output fields, the dataset is re-encoded to the Partner's destination domain at export time.
LiveRamp · Clean Room Engineering 7
Additionally Covered  DV-13417  Unmatched Records FF Logic
  • 📌
    Existing CRQs: No change in behavior, even if the account-level flag is enabled.
  • 🆕
    New CRQs: RETAIN_UNMATCHED_RECORDS capability applied by default.
  • ⚙️
    Opt-out for new CRQs: Set SKIP_UNMATCHED_RECORDS = true to disable default behavior.
  • 🔁
    Existing CRQs that want the capability: Remove the migrated SKIP_UNMATCHED_RECORDS property or set it to false.
